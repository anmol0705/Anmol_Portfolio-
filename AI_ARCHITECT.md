# PROJECT: ANMOL_PORTFOLIO_SOTA
# VIBE: F1 Telemetry, High-Frequency Trading, Dark Mode, Titanium, Bioluminescence.
# STACK: Next.js 14 (App Router), Tailwind CSS, React Three Fiber (R3F), GLSL Shaders.

## CORE DIRECTIVES (DO NOT BREAK):
1.  **NO SCROLLBARS:** The experience is immersive. Use custom scroll dampening (Lenis).
2.  **PERFORMANCE FIRST:** No heavy textures. Use procedural shaders.
3.  **TYPE SAFETY:** TypeScript is non-negotiable. No `any` types.
4.  **COMPONENT ATOMIZATION:** Build small, isolated components. Never build a monolithic file.
5.  **MATH OVER MEDIA:** Do not use images/videos unless necessary. Use Math/Shaders for visuals.

## VISUAL LANGUAGE:
- Background: #051821 (Deep Jungle) -> #B87333 (Copper) -> #2C2C2C (Titanium).
- Fonts: JetBrains Mono (Data), Editorial New (Headlines).
- Interaction: Fluid physics on hover.
